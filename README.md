A Python 3.13 forecaster that predicts Grand Theft Auto VI's launch-day Twitch viewers hour by hour (hours 2-24, five quantiles each) from the first hour's print, using a per-hour local-linear log regression over past big game launches shipped inside the case file.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
